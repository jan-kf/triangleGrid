# Triangle Grid

This is an implementation for the triangle grid problem that can do the following:

1- Take pixel X & Y coordinates and resolve to the specific triangle selected by way of the row and column.

2- For a letter and number triangle designator, produce its X & Y coordinates.

## How to use

In the terminal, run `python run.py` and follow the input instructions to specify the height, width, number of rows, and number of columns in order to initialize the Triangle Grid properly.

height, width are in pixel units (integers) -- They do not need to be the same value.

row count and column count are in integers, but the ratio of height/rows and width/columns needs to result in an integer.

row and column count also do not need to be the same value.

Once the Triangle Grid is initialized, you can choose between searching for triangle labels by coordinates, or searching for vertices by a triangle label.

## Tests

In the terminal, running `python tests.py` you'll run a series of tests on the code.
